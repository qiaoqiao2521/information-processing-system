# 阅读工作台前端优化

## 目标

用 Figma 可编辑方案改善信息阅读、组合筛选和原文入口，接回现有 React Router 前端并更新 436 公网。

## 实施

1. 核对真实页面、当前本地代码和 436 版本。
2. 复用 Figma Simple Design System 的搜索、按钮；仅补新闻条目组件。制作桌面和手机方案。
3. 分离来源与分类筛选，搜索保留条件；突出摘要与原文，解释精选日期。
4. 通过类型、构建、网页测试及真实 API 交互验证。部署只替换 web，保留回退镜像。
5. 核对公网，提交并推送有效成果。

## 设计

- 配色：正文 #162e35、次要正文 #53676f、青绿 #087f8c、背景 #f4f7f8、表面 #ffffff、分隔 #dce7ea。导航采用 #162e35。
- 中文字体：Figma Noto Sans SC；网站系统中文无衬线，避免外部字体请求。标题 30/20px，摘要 15px、1.8 行高。
- 桌面：220px 导航 / 有界阅读列 / 仅宽屏显示的阅读提示；手机：单列、完整搜索、两层可横滑筛选。
- 标注本页内容的真实最新日期；链接全部一手动态。读取不触发模型。

## 验收

- Figma 含编辑文本、组件实例和自动布局，非整页截图。
- 来源与分类可叠加，搜索与 AI 加工筛选保留条件，分页不沿用旧页码。
- 收藏、文章打开、返回、原文入口正常；手机无横向溢出；深色可读。
- 436 web 仅 loopback 8088，现有 API、worker、数据库及定时任务不变。

## 采用经验

采用 Wiki/自动化开发范式与智能体协作「按当前任务选择验收依据」：设计看可编辑结构和截图，工程看真实交互，部署看公网读回；Make 预览不能证明真实后端可用。本次通过 Figma Design 官方接口直接构建设计，不依赖 Make 登录。

## 当前页面导入

用户要求把运行中的前端直接导入 Figma。使用官方 `generate_figma_design` 和捕获脚本，在临时预览中运行当前源码并读取现有公开 API。导入结果与改版草案一起保留。

- 一手精选：`16:208`，1440 × 1032，59 个文本图层。
- 全部动态：`14:208`，1440 × 8053，302 个文本图层。
- 捕获时间为 2026-10-11，不表示文章发表于该日；一手精选的最新内容仍发表于 2026-10-01。
- 修复 48 个不可用的 Liberation Mono 字体引用，使用 Figma 提供的 Roboto Mono。正文保留捕获结果，两个页面均无缺失字体、无整页图片填充。
- 导入是可编辑的页面现状，交互和组件库仍由后续工程接回。此次未修改或部署生产前端。
