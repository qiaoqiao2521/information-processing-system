# Make 地图版接回发现

## 基线

Make Version 8「更换背景为地图」取代早期浅色草案。下载原包没有真实 API 连接：示例新闻每7秒循环注入，随机延迟、固定队列与增长率；精选标题不可打开，动态链接为 #。使用原包视觉组件接回既有 React Router，未替换工程配置或升级 React/motion。

## 接口映射

| 入口 | 读取／状态 | 验收边界 |
| --- | --- | --- |
| 精选 | /api/site/timeline | 原游标、取消请求、历史快照恢复保留 |
| 全部／组合搜索／AI加工 | /api/site/pool | URL 条件保留、页码重置、最新／全文相关 |
| 指标 | /api/site/stats | 真实24小时入库、精选总数、启用信源；失败显示本页数量 |
| 文章／原文模式 | /api/site/items/:id[/original] | 既有详情、来源外链和全文权限 |
| 收藏 | aihot-starred-items 本机存储 | 复用原格式和收藏页面，不上传账号数据 |
| 事件／热点／日报／主题 | 原 stories/hot/reports/topics 路由 | 导航恢复，后端与发布层不变 |
| GPT重置／阅读工具／Agent接口 | 原 codex-reset/reading-tools/agent 路由 | 无新采集、模型任务或通知 |

来源筛选是原来的资讯／X／一手频道，不冒称支持任意信源 ID 的全库筛选。六类分类采用 industry 的真实 key，未把 Make 的“开源”展示分类改写成后端新分类。

## 视觉与可靠性

- 地图和常态弧线是装饰；不宣称真实流量或服务器地理位置。
- 日期映射优先原发表日期，缺失时用真实时间线日期；不再固定2025或自动标今天。
- 已AI复核的加工稿没有本站模型分数，不能据此再标待处理。
- 原标题解码按动画帧计数，后台标签页降帧后长期无法完成；改为750毫秒的实际时间进度。
- 保留减少动效偏好；暂停标题乱码和地图循环。手机分类独立横滑，增加搜索及原文/收藏入口。
- 新依赖固定为 d3-geo 3.1.1、topojson-client 3.1.0、world-atlas 2.0.2；保留依赖自带许可证。部署复用436现有Node24构建镜像，只切web。

## 采用经验
