## 本次范围

### 2026-10-13 实施范围更新

用户明确“不加账号系统，先加其他的”。实现本机“我的”、最近阅读、正文位置恢复、关注来源、加工任务与手工结果记录，以及数据导入导出。复用 Make 视觉和公共读取层，不新增读者账号或自动跨端同步。

实施顺序：本机状态与兼容导入 → 阅读位置和任务记录 → 个人页及来源筛选 → 测试和浏览器验收 → 436 增量部署与公网验收 → 提交推送。

验收关注旧数据保留、正文变化阻止错误恢复、存储失败不报成功、任务复制不冒充模型完成，以及手机和电脑入口。

1. 检查 `myProfile`、`userProfile`、`account` bundle 和相关原生模型。
2. 对照当前实际使用的 Make Workbench、收藏、已读状态及管理员鉴权。
3. 区分 APK 已观察事实、本站建议和仍待验证的能力。
4. 留下可实施的页面结构和数据归属方案，沿用 Make 的视觉样式。

原结构分析已完成；当前继续实现以上用户批准的本机能力，不增加采集、模型调用、定时任务或公开内容。

## 验收

- 引用 APK 的具体 bundle、字符串编号或 Java 行号。
- 使用 `root.tsx` 实际挂载的 Workbench 判断本站入口，避免误把旧导航当成现状。
- 给出阅读行为、个人数据和管理权限各自的现状及落点。
- 不把静态字符串、反编译成功或账号存在当成真实用户流程验收。
