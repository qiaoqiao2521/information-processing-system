# 使用说明

本站由木乔维护，提供公开信息的阅读索引、摘要与事件整理。反馈入口为站内“反馈”页。本说明自 2026-10-01 起适用。

## 内容与出处

每条内容保留来源和原文链接；迁移存量标明未重新评分。模型生成的摘要、分类和事件关系可能有误，请以原文为准。原文版权归各来源所有，站内全文展示和全文 RSS 默认关闭。

## 阅读与接口

网站、RSS、公开 API 和 MCP 可匿名读取。使用聚合结果时请保留来源，转载原文须遵守来源方自己的许可。请按缓存时间轮询；遇到 429 时遵守 Retry-After。

## 更正与下架

来源方可通过反馈页说明相关原文链接及希望更正、下架或调整展示的内容，由维护者处理。
