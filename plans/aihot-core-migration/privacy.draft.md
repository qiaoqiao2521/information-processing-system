# 隐私说明

本站由木乔维护，阅读无需账号。隐私相关问题可通过站内“反馈”页提交。本说明自 2026-10-01 起适用。

## 浏览器本地数据

收藏、已读、主题偏好和反馈草稿保存在当前浏览器中；换设备不会自动同步，清除浏览器数据后可能消失。

## 反馈与后台

提交的反馈、选填邮箱、页面地址和附加截图保存在服务器上，用于处理反馈。软件根据网络地址和浏览器类别生成用于限流的标识。后台使用管理员会话，普通阅读不要求登录。

## 网络与第三方

公网访问经过 Cloudflare Tunnel。服务器与 Cloudflare 可能按其配置处理访问元数据和服务运行日志。本站没有额外接入访客统计工具。

点击原文后适用来源网站的隐私规则。模型加工只在后台执行；公开来源的文章材料会发送到所配置的模型接口，读者的收藏与已读记录不会因此发送给模型。

## 联系

反馈资料的查询、更正或删除请求请通过反馈页提交，并附上可定位的反馈信息。
