# NewsNow 与 ArXivHub 自托管

## 目标和范围

用户要求将 NewsNow 和此前的论文工具站部署到436，信息站只增加本地访问入口，保留官方站点和开源项目说明。论文项目已定点确认为 Peaceful-World-X/ArXivHub。复用开源应用，不另写热点或论文平台。

根Codex统筹源码、部署与Git交付；原「信息源」对话核对网站入口，并在根确认loopback就绪后，通过既有官方cf连接创建两条DNS及追加专用隧道路由。子Agent核对官方上游、历史身份和独立公网浏览器行为。所有共享文档由根串行更新。

## 路径

1. 核对现有源码、运行服务、域名和两个上游版本、许可及部署要求。
2. 固定版本，独立loopback部署，保留许可证和来源；不迁移账号。
3. 经现有域名/Tunnel接入独立origin，沿用信息站阅读工具的卡片与单篇论文入口。
4. 实测页面、前端资源、真实热点源、论文跳转和重启恢复；仅按实际证据宣称可用。
5. 更新部署/回退说明，提交推送受控仓库，核对远端SHA。

不改信息站评分、模型、采集时钟、数据库或个人阅读数据，不改公众号写作流程。

采用知识库「开发知识入口→历史工具检索」的身份核对方法；索引摘要只定位，当前文件与实际服务分别核实。

当前服务、域名和网页入口已交付；最终验证、已知限制及Git整合状态以progress.md为准。
